# MPI Evidence

The `task-manager/` directory contains Task Manager screenshots captured during MPI executions. The images show different process counts and workload variants from the course experiments.

The images show the twenty logical CPU graphs of the Intel Core i7-12700 under different process counts and workload variants. They support a qualitative discussion of operating-system load distribution, but they do not by themselves establish process affinity or guarantee that one MPI process ran on one distinct core.
